# Task 05: الوصول عن بعد من الموبايل بدون سيرفر (DentApex Cloudflare Tunnel & PWA Mobile Access)

## 1. الهدف الهندسي والمعماري
تمكين الطبيب من فتح برنامج **DentApex** بكافة ميزاته السريرية والإدارية والمالية من هاتفه الذكي (iOS أو Android) أو لابتوبه الشخصي من أي مكان خارج العيادة، مع بقاء البيانات مخزنة على كمبيوتر العيادة حصراً، وبدون دفع سنت واحد في سيرفرات سحابية (تكلفة الاستضافة 0$)، وبدون فتح بورتات في الراوتر (Zero Port Forwarding)، مع ضمان قابلية النقل الكاملة (Portability) بمسارات نسبية ديناميكية (%~dp0).

---

## 2. التحصينات الأمنية والمعمارية الصارمة

1. **المنفذ الموحد للواجهة والبروكسي (Port 7070)**:
   - يتم توجيه نفق Cloudflare المشفر حصراً إلى خادم **Caddy** المحمول على المنفذ `7070`.
   - خادم Caddy يقدم الواجهة الثابتة (Nuxt SPA) ويقوم ذاتياً بالتمرير العكسي (Reverse Proxy) لطلبات `/api/*` إلى خادم الباك إند FastAPI على المنفذ `7071` مع دعم تدفق الذكاء الاصطناعي (`flush_interval -1`).
2. **معمارية Same-Origin وغلق ثغرة الـ CORS**:
   - نظراً لأن Caddy يخدم الواجهة والـ API على نفس النطاق الموحد، فإن المتصفح لا يرسل طلبات Preflight `OPTIONS` من الأساس.
   - تبقى إعدادات CORS في الباك إند مغلقة وآمنة بدون أي Wildcards أو Regex غير ضروري.
3. **مسار الـ API النسبي للموبايل (`apiBaseUrl: ""`)**:
   - تم ضبط مسار الـ API الافتراضي في الواجهة ليكون نسبياً `""` لتقوم الهواتف الذكية بالاتصال التلقائي برابط النفق النشط (`https://<clinic-url>/api/...`) بدلاً من البحث عن الخادم داخل الموبايل نفسه.
4. **توليد رمز الـ QR عبر أمر `curl` المدمج**:
   - طباعة رمز الاستجابة السريعة (QR Code) للنفق السريع داخل سكريبت الدفعة باستخدام خدمة `qrenco.de` المفتوحة عبر أمر `curl` المدمج بويندوز:
     ```cmd
     curl -s https://qrenco.de/%TUNNEL_URL%
     ```
5. **الإيقاف القسري للشجرة الكاملة لعمليات النفق (Process Tree Force Kill)**:
   - لضمان عدم بقاء أي عمليات معلقة في الذاكرة:
     ```cmd
     taskkill /IM cloudflared.exe /F /T >nul 2>&1
     ```

## 3. الأكواد والسكريبتات التنفيذية

### 3.1 سكربت تحميل الأداة المحمولة تلقائياً
- **المسار**: `bin\cloudflared\download_cloudflared.ps1`
- يقوم بتحميل النسخة الرسمية لنظام ويندوز 64-بت من مستودع Cloudflare على GitHub وفحص سلامتها وحجمها تلقائياً.

### 3.2 سكريبت التحكم والربط السحابي التفاعلي
- **المسار**: `bin\setup_remote_access.bat`
- **المشغل السريع**: `DentApex-Remote.bat`
- يدعم خيارين رئيسيين:
  1. **Quick Tunnel (trycloudflare.com)**: نفق فوري مجاني بدون دومين مع طباعة الـ QR Code والتنبيه لصفحة Cloudflare Anti-Phishing Interstitial للمرور للشاشة الرئيسية.
  2. **Named Subdomain Tunnel (`*.yourdomain.com`)**: نفق دائم ومستقر مخصص لعيادة الطبيب، خالي من أي صفحات اعتراضية، مع توليد ديناميكي لملف `config.yml` بمسارات نسبية معزولة %~dp0.

## 4. تطبيق الويب التقدمي وتثبيت الموبايل (PWA Mobile Installation)
عند فتح الرابط السحابي على الموبايل:
1. يظهر تنبيه فوري في المتصفح: **إضافة DentApex إلى الشاشة الرئيسية (Add to Home Screen)** بفضل ملف `manifest.webmanifest`.
2. يتحول إلى أيقونة تطبيق أصلية على هاتف الطبيب، تفتح بملء الشاشة (`standalone`) بدون شريط متصفح وبألوان هوية DentApex (`#0EA5E9`).
3. تجربة استخدام مطابقة للتطبيقات الأصلية (Native App Feeling) وسرعة تصفح فائقة.
