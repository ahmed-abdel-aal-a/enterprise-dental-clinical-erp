# Lab orders

Track work sent to an external dental laboratory for a patient —
crowns, bridges, dentures, implants and more — from the day it is sent
to the day it comes back.

Each order links a patient, a laboratory contact (managed in
**Contacts**), and the case details the lab needs: tooth reference,
impression type, antagonist information and Vita Classical shade.
