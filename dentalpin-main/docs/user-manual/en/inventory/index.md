# Inventory

Standalone stock list with low-stock alerts: clinic items with current
quantity, minimum threshold and a per-item badge/alert when stock
reaches the minimum.

The whole team can read and write by default (operational data, not
sensitive).

## Screens

- [Stock list](./screens/inventory.md): category and low-stock filters,
  quick +/- adjustments, item creation/editing, delete with
  confirmation.
