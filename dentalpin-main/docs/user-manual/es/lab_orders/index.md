# Trabajos de laboratorio

Sigue el trabajo enviado a un laboratorio dental externo para un
paciente — coronas, puentes, prótesis, implantes y más — desde el día
que se envía hasta que vuelve.

Cada trabajo vincula un paciente, un contacto de laboratorio (gestionado
en **Contactos**) y los detalles del caso que el laboratorio necesita:
diente o referencia, tipo de impresión, información del antagonista y
color Vita Classical.

## Pantallas

- [Nuevo trabajo](./screens/new.md): formulario para enviar trabajo.
- [Trabajos de laboratorio](./screens/index.md): lista con seguimiento
  de estado y cambios en línea.
